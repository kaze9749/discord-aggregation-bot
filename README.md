# Discord Aggregation Bot

## 概要
指定したDiscordチャンネルのメッセージを、絵文字・画像有無・ユーザ・期間など様々な条件で集計するBotです。

## 主な機能
- 絵文字が付いたメッセージ件数の集計
- 画像付きメッセージのみ抽出
- 指定期間・ユーザ・チャンネルでフィルタ
- 最も投稿数の多かったユーザ表示
- 柔軟なコマンド引数で指定可

## コマンド例

```sh
!collect channel=ライブ emoji=👏,👍 image_only=True
!collect channel=ライブ emoji=👏👍 from=2024-05-01 to=2024-05-16
!collect channel="雑談" emoji=👏 show_top_user=True

## 必要なBot権限

BotをDiscordサーバーに追加する際、以下の権限を付与してください。

| 権限名（日本語）            | 英語表記                    | 必須/推奨 | 用途・備考                    |
|----------------------------|-----------------------------|-----------|-------------------------------|
| メッセージの表示           | Read /View Channels         | 必須      | チャンネル内メッセージ取得    |
| メッセージ履歴の表示       | Read Message History        | 必須      | 過去のメッセージを参照        |
| メッセージの送信           | Send Messages               | 必須      | 集計結果を返信                |
| リアクションの追加         | Add Reactions               | 必須      | Botのリアクション返信         |
| ファイルの添付             | Attach Files                | 推奨      | 画像判定機能を利用する場合    |
